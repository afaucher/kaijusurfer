# Kaiju Surfer

A mobile-first HTML5 prototype. You steer a purple multi-armed kaiju up an endless city maze, pluck energy as you go, eat the army, and outrun the wave.

Open `index.html` in a browser; there's no build step. On desktop, use the arrow keys or WASD to steer, Space for the laser, X for the claw and P to pause.

There are two visual styles to compare: **Neon arcade** and **Pixel city**. Switch between them from the title screen or the HUD.

See [DESIGN.md](DESIGN.md) for the open questions and recommended answers.
